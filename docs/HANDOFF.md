## 決定済みのこと
- 300倍超は買わない（市場もAIも確率を過大に見ていて、回収率74%）。
- 推奨はオッズ監視が締切直前のオッズで判定する。1時間ごとの採点（live-score）と過去分の取得（backfill）の定期実行は止めた。
- 推奨は2つの買い方A/Bを並行で記録し、どちらが良いかはデータが溜まってから決める。
- 見送り条件（G3、ナイター、チャレンジ、2着が別ラインの単騎など）は、ライン補正を入れたあとは効かなくなったので使っていない。
- 調子・ペアの相性はオッズに織り込まれていて、単独では効かない（映像の数値と合わせて再検証する）。
- 映像分析は Gemini を使う。着順などは渡さない盲検で、確認問題（最終バック先頭、上位3着、S/B）で読み取りの正確さを照合し、外れたレースは捨てる。重要項目は `true_strength`、`trouble_cost`、`reserve`。
- 変更は main に直接 push。データは data ブランチ。

## 分かっていること（検証の要点）
- 公開情報はほぼ全部オッズに入っている。唯一安定した偏りは「番手→先頭は買われすぎ」「ラインで決まる目全体が約5%安い」。
- **締切前に期待値が高く見えた目ほど、確定までにオッズが下がる**（友達HKさんのデータ、締切2.7分前→確定）：
  - 期待値1.0〜1.1 → 平均0.91倍、1.1〜1.2 → 0.87倍、1.2〜1.3 → 0.81倍。上乗せ分の約半分が消える。
  - 10〜300倍の目全体は、むしろ平均7〜11%上がる。
- 11/20の監視の推奨（締切2分後のオッズとの比較、確定ではない）：Aは2点でほぼ横ばい、Bは5点で平均0.81倍（183.3→84.7倍、22.2→11.4倍など）。同じレースの10〜300倍全体は約2%上昇。締切2分後のオッズは確定からさらに中央値で約1割ずれるので、確定オッズでの比較は 11/21朝の集計を待つ。
- 判断には各買い方で少なくとも1,000〜2,000点が必要。Aは1日十数点以下なので数か月かかる。A/Bの比較は「Bにだけ入る10〜50倍・期待値1.1〜1.2の部分」がプラスかで見ると早い。
